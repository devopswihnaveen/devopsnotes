## 📌 Waterfall vs Agile vs DevOps (Real-World Analogy)

### 🎓 School Management System

**Stakeholders**
- Students  
- Teachers  
- Parents  
- Principal / Staff  
- Management  
- Government  

**Reality**
- Students don’t study from Day-1  
- Teachers don’t teach from Day-1  
- Parents worry from Day-1  

**Result**
- Only **20–30% success**
- **70% failure**

### Problems
1. Fear only during exam time  
2. No continuous evaluation  

### Improvements
| Method | Result |
|------|-------|
| Unit Tests | 30–35% |
| Quarterly / Half-Yearly | 80% |
| Daily Slip Tests | 95% |

### Mapping to Software Models
| Education | Software |
|---------|---------|
| Gurukul | Waterfall |
| Unit Tests | Agile |
| Daily Tests | DevOps |

## 📌 Waterfall Model
- Long requirement phase (1 year)
- Development & testing together
- Late defect detection
- High rework cost
- Example: **Ferrari delivered as Maruti 800**

---

## 📌 Agile Model
- Sprint based (2–4 weeks)
- Continuous feedback
- Early defect detection

**Example Sprint**
- Signup & Login
- 15 days Dev + 15 days Test
- 10 defects → 2 invalid

---

## 📌 DevOps Model

### Definition
**DevOps is the practice of developing, building, deploying, and testing software on the same day using automation tools to improve collaboration, speed, and quality.**

### Goals
- Faster delivery
- Continuous testing
- Automation
- Collaboration

## 📌 Linux Fundamentals

|-----|--------|
